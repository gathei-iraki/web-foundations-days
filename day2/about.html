About QuickNotes

QuickNotes is a simple note-taking app for jotting down ideas, reminders and to-do items the moment they come to you. It keeps all your notes in one place so you can find them again quickly.

How to use QuickNotes

  1. Open the Home page.
  2. Type your note into the note box.
  3. Click "Save" to add the note to your list.
  4. Delete a note when you no longer need it.

Features

  • Create and save notes instantly
  • View all your notes in one list
  • Delete notes you no longer need
  • Works in any modern web browser

Keyboard shortcuts

Shortcut Action
Ctrl + N Create a new note
Ctrl + S Save the current note
Delete Delete the selected note
